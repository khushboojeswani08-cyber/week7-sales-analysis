Sales Data Analysis Dashboard

Project Description

A Python-based sales data analysis project using Pandas and Matplotlib. It analyzes sales records, calculates business metrics, identifies monthly sales trends, and generates charts and Excel reports.

Objectives

- Load sales data from a CSV file.
- Clean and preprocess sales records.
- Calculate total sales and average order value.
- Analyze sales by product category.
- Identify monthly sales trends.
- Generate charts and an Excel report.

Requirements

- Python 3.10 or later
- pandas
- matplotlib
- numpy
- openpyxl
- jupyter

Installation

Install the required libraries:

pip install -r requirements.txt

How to Run

Run the following command from the project directory:

python main.py

Analysis Features

1. Sales data loading
2. Data cleaning and duplicate removal
3. Total sales calculation
4. Average order value calculation
5. Category-wise sales analysis
6. Monthly sales trend analysis
7. Excel report generation
8. Sales visualization using charts

Output Files

After successfully running the program, the project generates:

- "data/processed/cleaned_sales_data.csv"
- "reports/sales_report.xlsx"
- "reports/monthly_sales.png"
- "reports/category_sales.png"
